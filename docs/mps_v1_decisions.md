# MPS v1 decisions required before implementation

No item below is decided merely by documenting the provisional references. Resolve each scientific, compatibility, or costly-computing item with the repository owner before implementation or baseline execution.

## Recommended smallest first target

Build the first clean target around exactly one user-selected field, split code 1 (interleaved) only, one single-case command, and no sweep submission. This confines the first comparison to one input/output path while preserving the provisional reference's interleaved option ([reference contract](mps_v1_reference_contract.md#tensorization-and-ordering)).

The particular field, dataset, timestep, and regression output remain **UNRESOLVED**. They must not be inferred from the wrapper's active list because its prose and arrays disagree ([`Julia/00mps_calc.slurm:13-16`](../Julia/00mps_calc.slurm#L13-L16), [`Julia/00mps_calc.slurm:21-35`](../Julia/00mps_calc.slurm#L21-L35)).

## Decisions to obtain

1. **Authoritative scope:** Confirm that only the active CLI path in `Julia/0mps_calc.jl` is behavior to match, and identify whether any other historical script must be compared before implementation. Consequence: this determines whether apparent differences are incompatibilities or out-of-scope history ([`Julia/0mps_calc.jl:606-870`](../Julia/0mps_calc.jl#L606-L870)).
2. **First case:** Select the dataset/path, field, and timestep for the single-case baseline. Consequence: this fixes both the binary input and the scientific quantity being compared; the wrapper currently lists multiple fields at timestep `0198` ([`Julia/00mps_calc.slurm:21-26`](../Julia/00mps_calc.slurm#L21-L26), [`Julia/00mps_calc.slurm:46-48`](../Julia/00mps_calc.slurm#L46-L48)).
3. **Input layout:** Confirm full-grid dimensions, endian conversion, scalar dtype, axis convention, physical units, and the 512-cube crop. Consequence: any mismatch changes the values or their spatial positions before tensorization ([`Julia/0mps_calc.jl:825-842`](../Julia/0mps_calc.jl#L825-L842)).
4. **Bit convention:** Define the significance of each binary index generated by Julia's reshape and how bits map to named spatial axes. Consequence: the same field values can enter the MPS in a different site order even when both implementations call it “interleaved” ([`Julia/0mps_calc.jl:181-217`](../Julia/0mps_calc.jl#L181-L217), [`Julia/0mps_calc.jl:317-337`](../Julia/0mps_calc.jl#L317-L337)).
5. **Shape validation:** Decide whether every axis must be an equal power of two and whether invalid shapes receive an early error. Consequence: strict validation may intentionally differ from the reference's first-axis-derived reshape behavior ([`Julia/0mps_calc.jl:317-325`](../Julia/0mps_calc.jl#L317-L325)).
6. **Compression mode:** Choose cutoff or maximum bond dimension and the single test value. Consequence: the MPS constructor receives different keyword combinations, including an explicit zero cutoff in `chi=` mode ([`Julia/0mps_calc.jl:381-394`](../Julia/0mps_calc.jl#L381-L394), [`Julia/0mps_calc.jl:846-850`](../Julia/0mps_calc.jl#L846-L850)).
7. **Normalization and fidelity:** Decide whether the field is normalized, what fidelity/error means, and over which representation it is computed. Consequence: these choices define both numerical behavior and acceptance criteria; the active compression path contains no explicit normalization or fidelity calculation ([`Julia/0mps_calc.jl:366-413`](../Julia/0mps_calc.jl#L366-L413)).
8. **Filtering and physics:** Decide whether any filtering operator or physical formula belongs in v1, including units. Consequence: adding either would go beyond the active reference, which passes cropped binary values directly to `mps_truncate` ([`Julia/0mps_calc.jl:831-850`](../Julia/0mps_calc.jl#L831-L850)).
9. **Compatibility environment:** Decide which captured Julia/package/BLAS/thread/module environment is authoritative. Consequence: package and linear-algebra differences may alter decomposition and truncation results; only a Julia path and thread settings are presently encoded ([`Julia/0mps_calc.jl:1-13`](../Julia/0mps_calc.jl#L1-L13), [`Julia/00mps_calc.slurm:18-19`](../Julia/00mps_calc.slurm#L18-L19)).
10. **Regression outputs:** Choose which MAT variables, metadata, link dimensions, dtype, filenames, and numerical metrics must match. Consequence: this defines the baseline artifact and prevents accidental approval based on only one observable ([`Julia/0mps_calc.jl:398-425`](../Julia/0mps_calc.jl#L398-L425), [`Julia/0mps_calc.jl:858-866`](../Julia/0mps_calc.jl#L858-L866)).
11. **Tolerance policy:** Set tolerances only after the historical environment and observed output dtype are known. Consequence: no fabricated threshold becomes a false compatibility guarantee ([reference contract](mps_v1_reference_contract.md#runtime-and-dependencies), [baseline plan](../validation/mps_v1_baseline_plan.md)).
12. **Historical quirks:** For every discovered mismatch—such as prose versus active wrapper arrays—decide explicitly whether it is intended behavior or a historical bug. Consequence: fixes will be deliberate rather than silently folded into the clean implementation ([`Julia/00mps_calc.slurm:13-16`](../Julia/00mps_calc.slurm#L13-L16), [`Julia/00mps_calc.slurm:21-35`](../Julia/00mps_calc.slurm#L21-L35)).
13. **CRC execution:** Approve resources and the exact single case before any submission; approve a sweep separately if one is later needed. Consequence: the initial target does not inherit the wrapper's 28-task array or its 64 GiB/two-hour request ([`Julia/00mps_calc.slurm:2-11`](../Julia/00mps_calc.slurm#L2-L11)).
